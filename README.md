## 🔍 Troubleshooting Tips

Common issues usually stem from hardware settings or file formats. Review these solutions if you encounter problems.

*   **Application closes unexpectedly**: Close other programs that use the graphics card, such as high-end video games or 3D editing software. Check that you have the latest drivers from your graphics card manufacturer.
*   **Video file does not load**: Ensure your video file uses common formats such as MP4, MKV, or AVI. Large video files might require extra time for the software to index the frames before processing.
*   **Slow performance**: Verify that the application uses the dedicated graphics card instead of the integrated processor. You can check this in the Settings menu under Hardware Acceleration.
*   **Installation errors**: Ensure you have enough space on your C: drive. If the installer hangs, try restarting your computer and running the file as an administrator.

The software creates several files after it finishes the analysis. The main output is a JSON file that contains coordinates for movement. You can import this file into animation software or data analysis spreadsheets.
